## 2. v4 镜头系统（新模块）

1. Camera（推拉摇移旋转变焦 + 手持 + 甩镜 + 视差 + 纵深 + 眩晕变焦）：每镜定义
   (t0, t1, start_pose, end_pose, ease, shake, whip)。渲染时把场景内容画进 1600×900
   大画布，逐帧做仿射采样（缩放/平移/旋转），背景网格层、数据流层、角色层用不同
   视差系数分别变换，产生真实纵深；甩镜=短时高速度缓动+运动鬼影；眩晕=前景推近、
   背景反向拉远（dolly-zoom）。
2. 角色调度表：每镜声明 position/景别/形态（全躯/半身/眼部特写/手部/剪影/负片/局部
   /PIP/分屏/多窗/OFF），角色独立变换并跟随表情与面部故障锚点。
3. 信息层（每帧 4–10 层，按镜表执行）：A 深空底+网格；B 数据流/代码雨；C 突触/电路；
   D HUD 全息窗（日志流、频谱、心电、电量、锁定框、小地图）；E 主视觉；F 数学可视化
   （点阵/圆/波/切线/∞/坐标系/电路/时钟/公式）；G 角色层；H 情绪层（红圈、批注、
   水渍、裂纹、乱码）；I 字幕层。所有层与歌词/feed 绑定，不是无意义堆砌。
4. 效果模块（numpy 向量化，缓存预计算）：霓虹光晕 bloom、色差、镜头光晕（按亮点）、
   体积光、粒子/光尘、数据雨、网格波形变形、故障切片、景深（远景模糊）、运动鬼影、
   慢动作（局部时间缩放）、反射（HUD 玻璃倒影）。
5. 保留并加强：c(t) 腐蚀递进、局部马赛克（眼角/嘴角/指尖蔓延）、语言暴走
   （S17–S18 文字增殖重叠乱码膨胀碎裂）、红字高亮、字幕下划线 110.41s 蓝转红。
